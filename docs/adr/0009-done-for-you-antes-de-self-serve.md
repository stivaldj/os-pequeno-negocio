# Operamos para o cliente antes de vender software que ele opera

A v1 atende empresa com CNPJ em modelo done-for-you: nós configuramos, rodamos e ajustamos o Agente de cada Conta, com poucos clientes e ticket alto. Autônomos entram depois, em self-serve, quando o produto rodar sozinho nas primeiras Contas.

Não é só decisão comercial, é decisão de arquitetura e de calendário. Self-serve exige billing, Embarque autônomo, suporte e documentação — e, do lado das integrações, exige App Review da Meta, seis a doze semanas, porque terceiros passariam a autenticar sozinhos. Operando nós mesmos, partner access mais System User já bastam e a primeira campanha por código sai em cerca de uma semana. O software se forma por baixo do serviço, feito das partes que cansamos de repetir à mão.

## Consequências

O produto vai nascer com buracos de auto-serviço, de propósito. Cada buraco só é fechado quando doer na operação — essa dor é o critério de priorização.
