# Labels de triagem

As skills falam em cinco papéis canônicos. Esta tabela mapeia cada papel para a label real usada neste repo.

| Papel na skill    | Label neste repo  | Significado                                    |
| ----------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Precisa ser avaliada                           |
| `needs-info`      | `needs-info`      | Esperando informação de quem abriu             |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada, pronta para um agente |
| `ready-for-human` | `ready-for-human` | Exige implementação humana                     |
| `wontfix`         | `descartado`      | Não será feita                                 |

## Labels de categoria

Ortogonais às de triagem — toda issue recebe uma:

`bug` · `feature` · `chore` · `decisao`

## Regra

Tickets vindos de `/to-tickets` já nascem agent-ready. **Não triar.** A triagem existe para issues criadas por terceiros.
